# 个人贡献者许可协议（v1.0，OpenAI）

> 原文：`AI/codex/docs/CLA.md`

基于 Apache Software Foundation Individual CLA v2.2。

当你在 Pull Request 上评论 **“I have read the CLA Document and I hereby sign the CLA”** 时，你（“Contributor”）即同意以下条款，这些条款适用于你向 **OpenAI Codex CLI project**（“Project”）提交的过去和未来任何“Contributions”。

## 1. 定义

- **Contribution**：提交到 Project 的任何原创作品，包括代码、文档、设计等。
- **You / Your**：发布接受评论的个人或法律实体。

## 2. 版权许可

你授予 OpenAI, Inc. 以及接收 Project 分发软件的所有接收方一项永久、全球、非独占、免版税、不可撤销的许可，用于复制、准备衍生作品、公开展示、公开表演、再许可和分发你的 Contributions 及其衍生作品。

## 3. 专利许可

你授予 OpenAI, Inc. 以及 Project 的所有接收方一项永久、全球、非独占、免版税、不可撤销（除下述情况外）的专利许可，用于制造、委托制造、使用、销售、许诺销售、进口和以其他方式转让你的 Contributions，无论单独使用还是与 Project 结合使用。

如果任何实体提起专利诉讼，声称 Project 或某项 Contribution 侵犯专利，则你授予该实体的专利许可终止。

## 4. 陈述

1. 你有合法权利授予上述许可。
2. 每项 Contribution 要么是你的原创作品，要么你有权在本 CLA 下提交。
3. 你的 Contributions 按 **AS IS** 提供，不含任何形式的保证。
4. 如果上述任何陈述变得不准确，你会通知 Project。

## 5. 其他

本协议受美国加利福尼亚州法律管辖，不适用其法律冲突规则。若任何条款被认定不可执行，其余条款继续有效。
