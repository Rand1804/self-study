# Python SDK 示例

> 原文：`AI/codex/sdk/python/examples/README.md`

## 前置条件

先在 `sdk/python` 中准备环境并完成认证。

## 运行示例

```bash
cd sdk/python
python examples/01_quickstart_constructor/sync.py
python examples/01_quickstart_constructor/async.py
```

## 推荐第一次运行

先运行 quickstart constructor 的 sync 和 async 示例，确认 runtime、认证和 app-server 通信正常。

## 索引

示例目录按功能组织，覆盖同步/异步 client、登录、thread、turn、streaming 等常见用法。
